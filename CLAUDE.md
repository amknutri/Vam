# CLAUDE.md — repositório amknutri/Vam

Instruções para o Claude Code que trabalhar neste repositório.

## ATENÇÃO: repositório PÚBLICO

Qualquer pessoa na internet lê este repositório, e o histórico do Git guarda tudo, mesmo o que for apagado depois.

- **Nunca** gravar aqui senha, chave de API, token, credencial, número de telefone, dado de cliente ou dado financeiro pessoal.
- **Nunca** gravar aqui falhas de segurança, códigos (IDs) de arquivos do Drive ou endereços internos de sistemas (n8n, Evolution, Supabase).
- Detalhes ficam em lugares de acesso restrito: o Mural, o Drive da conta do Vamberto e os projetos do Claude. Aqui vai só o resumo e onde procurar.

## O que tem neste repositório

- Páginas de cadastro MRP (template-mestre, Dorismar, Tereza, Vamberto), publicadas.
- `CHECKLIST.md`: a seção **"Onde paramos"** da sessão do Claude Code que cuida da agente Nanda, do Núcleo Padrão e da manutenção do Mural.

## Como trabalhar com o Vamberto

- Ele é empreendedor, não técnico. Responder sempre em português do Brasil, linguagem direta, explicando antes de fazer.
- Decisões de dinheiro, escopo, prioridade, produção e qualquer coisa irreversível são dele.
- Mais Talentto tem prioridade total.

## Troca de sessão (regra do Vamberto, 02/11/2026)

O Claude Code avisa o Vamberto quando trocar de sessão (etapa grande concluída, conversa resumida automaticamente ou Contexto acima de ~60%). Antes de avisar, atualiza o Onde paramos, publica e diz "está tudo salvo". A sessão antiga é arquivada, não apagada, depois que a nova confirmar a leitura.

Na prática:
1. Atualizar a seção "Onde paramos" do `CHECKLIST.md`.
2. Publicar: commit e push no GitHub.
3. Dizer ao Vamberto: "está tudo salvo".
4. A sessão nova lê este `CLAUDE.md` e o `CHECKLIST.md` e confirma a leitura ao Vamberto.
5. Só então a sessão antiga é arquivada (nunca apagada).
